조건에 맞는 사례가 없다.
CH.2

AI가 맡은 일, 사람이 맡은 일

네 사례를 한 표에 놓으면 공통점이 보인다. 코드 작성은 대부분 AI가 했지만, 무엇이 맞는지 판단하는 장치(테스트 스위트, 기준 컴파일러, 공개 피드백)는 사람이 만들었다.

CH.3

벤치마크, 스타 수, 매출은 서로 다른 숫자다

빌드가 4.4배 빨라진 것과 GitHub 스타 39만 개, ARR 100만 달러는 각각 다른 것을 잰다. 그래서 하나의 순위로 줄 세우지 않고 종류별로 나눴다. 숫자를 누르면 출처가 열린다.

CH.4

아이디어: 이번 주말에 AI랑 만들어 볼 개발 도구 4개

사례에서 잘된 점을 가져와 새로 생각한 아이디어다. 카드 안의 데모는 인터넷 연결 없이 이 파일 안에서 실행되며, 데이터는 모두 가짜다.

IDEAS 표시가 붙은 카드는 이 문서에서 새로 낸 아이디어다. 실제 제품이나 성공 사례가 아니다. 데모에 나오는 커밋, 작성자, 수치도 모두 지어낸 것이다.

이 문서를 만든 기준

  1. 기준일은 2026-11-21이다. 출처마다 게시일을 적었고, 게시일이 없으면 열람일을 적었다. GitHub 스타와 포크 수는 2026-11-21에 GitHub 공개 API로 읽은 값이다.
  2. 구조 탭의 "실제 구조"는 해당 사례의 글, README, 화면에서 확인한 내용만 단순화해 그렸다. 확인하지 못한 부분은 점선과 "미확인"으로 표시했다. "따라 만든다면"은 이 문서의 가설이다.
  3. 벤치마크는 만든 쪽이 밝힌 측정 조건과 함께 적었다. 벤치마크와 매출, 스타 수를 같은 기준으로 비교하지 않았다.
  4. AI가 코드를 얼마나 썼는지는 만든 사람의 서술을 옮긴 것이며, 이 문서가 코드를 분석해 잰 값이 아니다.
  5. v02까지의 소비자 앱, 사내 도구 사례는 스택이 공개되지 않아 개발자 독자에게 맞지 않다고 보고 뺐다.
