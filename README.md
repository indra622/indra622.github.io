# 박호성 개인 블로그

AI 개발자 박호성의 기술 블로그입니다.

🔗 **사이트**: [https://indra622.github.io](https://indra622.github.io)

## 소개

음성인식과 자연어처리(NLP)를 전문으로 하는 AI 개발자의 기술 블로그입니다.

- 현재: 삼성화재 AI개발파트
- 이전: KB국민은행 금융AI센터
- 학력: 서강대학교 음성인식 전공 박사

## 주요 내용

- 음성인식 및 NLP 관련 기술 포스트
- AI 개발 경험 및 인사이트
- 오픈소스 프로젝트 기여 내용
- 연구 및 프로젝트 수행 이력

## 기술 스택

- **블로그 엔진**: Jekyll (GitHub Pages)
- **테마**: Clean Blog (커스터마이징)
- **폰트**: Pretendard
- **스타일**: SCSS/CSS
- **기능**: 다크모드, 반응형 디자인

## 로컬 실행

### 사전 요구사항

- Ruby (2.7 이상)
- Bundler
- Jekyll

### 설치 및 실행

```bash
# 의존성 설치
bundle install

# 로컬 서버 실행
bundle exec jekyll serve

# 브라우저에서 접속
# http://localhost:4000
```

### 빌드

```bash
bundle exec jekyll build
```

빌드된 사이트는 `_site` 디렉토리에 생성됩니다.

## 주요 파일 구조

```
.
├── _posts/              # 블로그 포스트
├── _layouts/            # 페이지 레이아웃
├── _sass/               # SCSS 스타일시트
├── _data/               # 경력 및 학력 데이터
├── assets/              # 정적 파일 (CSS, JS, 이미지)
├── img/                 # 이미지 파일
├── index.html           # About Me (메인 페이지)
├── posts/               # 블로그 목록 페이지
└── _config.yml          # Jekyll 설정 파일
```
